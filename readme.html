README

Simora is a free memecoin paper trading extension for Axiom, GMGN and Padre.

Practice live memecoin trading with virtual funds, track performance and test strategies without risking real money.

100% free. No activation key. No paid features. No wallet connection required.

Features

  • Multi-Platform Support: Works on Axiom, GMGN and Padre
  • Trading Panel: Simulate buys and sells directly on supported trading pages
  • Dynamic PnL Bar: Track balance, open positions and PnL while browsing
  • Quick Buy: Practice fast entries directly from supported token listings
  • Portfolio Calendar: Review daily trading performance and history
  • Chart Integration: View simulated trade markers and entry/exit information on supported charts
  • Auto Translate: Translate supported interface content while trading
  • Simora Social: Social paper trading features including friends and shared trading activity
  • Local Data Storage: Paper trading data and preferences are primarily stored in your browser

Installation

  1. Install Simora from the Chrome Web Store
  2. Open Axiom, GMGN or Padre
  3. Make sure the Simora extension is enabled
  4. Open a supported trading or token page
  5. Start paper trading with virtual funds

No account, activation key or payment is required.

Supported Platforms

  • Axiom

  • Padre

Usage

  1. Navigate to Axiom, GMGN or Padre
  2. Open a supported token or trading page
  3. Use Simora's paper trading tools to simulate entries and exits
  4. Track balance, positions and PnL
  5. Review your trading history and performance

Privacy & Security

  • No wallet connection required
  • No private key access
  • Simulated trades do not use real funds
  • Paper trading data and extension settings are primarily stored locally in your browser
  • Simora does not execute blockchain transactions for simulated trades
